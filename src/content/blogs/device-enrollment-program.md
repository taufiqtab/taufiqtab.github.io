## Ringkasan
DEP adalah aplikasi untuk mendukung **Device Enrollment Program** bersama Apple. Di project ini fokus saya adalah pengembangan **user management**, ditambah sebagian kecil **setup enrollment**.

## Latar Belakang
Program enrollment melibatkan banyak pengguna internal dengan wewenang berbeda. Hak akses harus diatur dengan rapi supaya setiap orang hanya bisa melakukan apa yang menjadi tugasnya.

## Fitur Utama
- **User management**: pengelolaan akun pengguna aplikasi.
- **Role & hak akses**: pembagian wewenang sesuai peran.
- **Setup enrollment**: bagian dari konfigurasi pendaftaran device.

## Teknologi
| Bagian | Teknologi |
| --- | --- |
| Framework | Laravel |
| Bahasa | PHP |

## Peran Saya
- Mengembangkan modul user management dan pengaturan role.
- Membantu sebagian setup enrollment.

## Tantangan & Pembelajaran
Mengerjakan bagian user management di project ini memberi dasar yang kemudian berguna saat membangun [UMS](/project/user-management-services) sebagai layanan user management terpusat.
