## 🎮 Tentang Game
**Hungry Orc Evolution** adalah game yang dikembangkan pada 2016. Dari judulnya sudah ketahuan: ada orc, dia lapar, dan dia berevolusi.

| Item | Detail |
| --- | --- |
| **Genre** | Casual |
| **Platform** | Mobile Game |
| **Periode** | 2016 |
| **Engine** | Unity 3D (C#) |
