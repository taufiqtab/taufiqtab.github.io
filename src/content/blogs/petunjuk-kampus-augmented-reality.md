## 🥽 Tentang Project
**Petunjuk Kampus Augmented Reality** memanfaatkan AR sebagai **petunjuk di lingkungan kampus**. Informasi ditampilkan di atas tampilan kamera, jadi mahasiswa baru atau tamu tidak perlu bingung mencari tempat.

## 🕹️ Info Game
| Item | Detail |
| --- | --- |
| **Genre** | Augmented Reality, Navigasi |
| **Platform** | Mobile AR |
| **Periode** | 2016 |
| **Engine** | Unity 3D (C#) |

## 🧰 Toolkit
Senjata andalan saya selama jadi game developer:

| Tool | Dipakai untuk |
| --- | --- |
| **Unity 3D** | Game engine: scene, physics, dan build ke platform tujuan |
| **C#** | Scripting gameplay dan logika game |
| **Blender 3D** | Modeling dan animasi aset 3D |
| **GIMP** | Tekstur dan aset gambar raster |
| **Inkscape** | Aset vektor: UI, ikon, dan sprite |

> Nyasar di kampus? Arahkan kamera saja.
