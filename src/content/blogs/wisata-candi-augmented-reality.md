## 🥽 Tentang Project
**Wisata Candi Augmented Reality** menghadirkan wisata candi lewat teknologi AR. Candi bisa dinikmati sebagai objek 3D di layar, cara yang lebih seru untuk mengenal warisan budaya.

## 🕹️ Info Game
| Item | Detail |
| --- | --- |
| **Genre** | Augmented Reality, Wisata |
| **Platform** | Mobile AR |
| **Periode** | 2016 |
| **Engine** | Unity 3D (C#) |

## 🧰 Toolkit
Senjata andalan saya selama jadi game developer:

| Tool | Dipakai untuk |
| --- | --- |
| **Unity 3D** | Game engine: scene, physics, dan build ke platform tujuan |
| **C#** | Scripting gameplay dan logika game |
| **Blender 3D** | Modeling dan animasi aset 3D |
| **GIMP** | Tekstur dan aset gambar raster |
| **Inkscape** | Aset vektor: UI, ikon, dan sprite |

> Jalan-jalan ke candi, dari genggaman tangan.
