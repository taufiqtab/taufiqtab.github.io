## 🥽 Tentang Project
**FlonAR** adalah aplikasi **Augmented Reality untuk pendidikan** yang dikembangkan pada Desember 2016–Januari 2017. AR membuat materi belajar muncul sebagai objek 3D di atas dunia nyata, jadi bukan cuma dibaca di buku.

## 🕹️ Info Game
| Item | Detail |
| --- | --- |
| **Genre** | Augmented Reality, Edukasi |
| **Platform** | Mobile AR |
| **Periode** | 2016 – 2017 |
| **Engine** | Unity 3D (C#) |

## 🧰 Toolkit
Senjata andalan saya selama jadi game developer:

| Tool | Dipakai untuk |
| --- | --- |
| **Unity 3D** | Game engine: scene, physics, dan build ke platform tujuan |
| **C#** | Scripting gameplay dan logika game |
| **Blender 3D** | Modeling dan animasi aset 3D |
| **GIMP** | Tekstur dan aset gambar raster |
| **Inkscape** | Aset vektor: UI, ikon, dan sprite |
