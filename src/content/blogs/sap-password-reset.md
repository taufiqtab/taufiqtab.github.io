## Ringkasan
SAP Password Reset adalah landing page **self-service** untuk karyawan yang perlu me-reset password **SAP S/4HANA** dan **Fiori**. Pengguna cukup mengisi form request tanpa perlu menghubungi helpdesk secara manual.

## Latar Belakang
Lupa password adalah salah satu permintaan support yang paling sering muncul. Jika setiap request harus melalui chat atau telepon, tim support tersita untuk pekerjaan yang berulang.

## Fitur Utama
- **Form request**: pengguna mengisi User ID dan memilih sistem.
- **Dukungan dua sistem**: SAP S/4HANA dan Fiori.
- **Self-service**: request masuk dengan format yang seragam.
