## 🎮 Tentang Game
**Trash Rush** adalah web based game yang dibuat di **Global Game Jam 2014**. Di game jam, ide, desain, kode, dan aset harus jadi dalam waktu yang sangat singkat.

Ini salah satu project game paling awal saya, dibuat saat kuliah di STT Terpadu Nurul Fikri.
