## 🎮 Tentang Game
Pengin ngerasain hidup bebas tanpa aturan ini-itu? Di **SecondWorld Adventure Freeroam**, game berbasis **MMO**, kamu bisa ketemu banyak pemain dari seluruh dunia dan bebas ngelakuin apa pun yang kamu suka.

## 🕹️ Info Game
| Item | Detail |
| --- | --- |
| **Genre** | MMO, Open World |
| **Platform** | Mobile Game · MMO |
| **Periode** | 2017 – 2018 |
| **Studio** | Binary Works Indonesia |
| **Engine** | Unity 3D (C#) |

## ✨ Fitur
- Berteman dengan orang baru
- Balap motor atau balap mobil
- Bertualang
- Ganti penampilan ala game dress up
- Battle melawan pemain lain

## 🎯 Tuntaskan Misi
Kumpulkan uang tambahan dengan menyelesaikan misi-misi yang sudah disiapkan. Uangnya bisa dipakai untuk memenuhi kebutuhanmu di game, misalnya beli senjata dan kendaraan. Makan? Tenang, di sini kamu nggak butuh makan, kamu terlahir kenyang sampai mati. Sungguh sebuah kenikmatan yang HQQ, bukan?

## 👯 Main Bareng Temen
Serunya berlipat ganda kalau dimainkan bareng teman. Pakai fitur **Teleport** untuk langsung pindah ke posisi temanmu berada.

## 🧰 Toolkit
Senjata andalan saya selama jadi game developer:

| Tool | Dipakai untuk |
| --- | --- |
| **Unity 3D** | Game engine: scene, physics, dan build ke platform tujuan |
| **C#** | Scripting gameplay dan logika game |
| **Blender 3D** | Modeling dan animasi aset 3D |
| **GIMP** | Tekstur dan aset gambar raster |
| **Inkscape** | Aset vektor: UI, ikon, dan sprite |

> Fitur Teleport bisa memindahkanmu ke posisi teman. Sayangnya belum bisa memindahkanmu ke hati gebetan.
